# Windows Duo · 摄像头驱动「悬浮玻璃」

在普通 Windows 笔记本上，用**自带的摄像头**识别上盖开合角度，实时复刻 iPhone Duo 的
**悬浮玻璃**开合效果：桌面像一块绕屏幕底边（铰链）转开的玻璃，靠近铰链处始终清晰，
越远离铰链越模糊、越暗，视线出界处变黑。全屏透明叠加层，**鼠标可穿透点击**，不影响正常使用。

架构、交互、渲染算法、工程化均移植自上游项目 WindowsDuo，
**仅把角度来源从「ESP32 + MPU6050 串口」换成「摄像头 ORB 特征匹配」**，无需任何外接硬件。

## 技术栈

设置窗口与 Class-Widgets **同框架、同控件库**：

| 层 | 用什么 |
|---|---|
| Qt 绑定 | **PySide6**（Qt 官方） |
| 界面 | **QML / Qt Quick**（声明式，GPU 场景图） |
| 组件库 | **RinUI**（FluentWindow / NavigationView / SettingCard / Slider …） |
| 主题 | RinUI 自带 Mica 与明暗；主色从 Windows 读取后覆盖 |
| 叠加层 | PySide6 的 QOpenGLWidget + GLSL（核心功能，保持原生 GL） |

## 原理

### 角度识别（`tracker.py`）
1. 笔记本上盖的摄像头随开合绕转轴转动。程序用 **ORB 特征匹配 + 单应矩阵分解**，实时算出
   上盖相对基准帧的俯仰角，再映射为折叠浓度。
2. 用「滑动关键帧 + 固定锚点校正」消除累计漂移，用 **One Euro 滤波**平滑抖动。
3. 用 CLAHE 局部对比度归一化抵抗自动曝光漂移。

### 渲染（`shaders.py` + `gl_core.py`）
- **逆投影模型**：界面固定在世界空间平面上不动；屏幕是一块玻璃，绕「铰链」（屏幕底边）
  向观察者方向转开。每个像素：眼睛 → 玻璃像素 → 延长交到界面平面 = 采样点。
  间隙越大 → 模糊半径越大、越暗；视线完全出界 → 纯黑。
- **Vogel 盘模糊**：`sqrt` 均匀面密度 + 黄金角 + 每像素随机旋转 → 磨砂玻璃颗粒感。
- **mip LOD 分级采样** + **边缘覆盖率平滑**，大半径也稳、不出硬边。
- 使用 **OpenGL 3.3 Core profile + GLSL 着色器 + VAO/VBO**（本机 Intel 驱动只提供
  forward-compatible 上下文，固定管线不可用，故走 core profile）。

## 环境

- Windows（带摄像头、支持 OpenGL 3.3）
- Python 3.10+（本项目在 3.12 上开发验证）

```bash
pip install -r requirements.txt
```

依赖：`opencv-python`、`numpy`、`PyQt6`、`PyOpenGL`、`PyOpenGL_accelerate`、`mss`、`Pillow`

## 运行

双击 `run_overlay.bat`，或：

```bash
python main.py
```

### 使用步骤

1. 上盖**完全展开**，让摄像头对着**有纹理的静止场景**（墙、书架等，别对着纯白墙或自己）。
2. 运行 `python main.py`。屏幕左上角会出现**「Duo 控制面板」**——一个带按钮的小窗口，
   实时显示 `fold`（折叠角）、浓度、匹配点数和状态。看不到它说明程序没起来。
3. 点面板上的 **「① 标定基准帧」**（状态会变成 `已标定` / `追踪中`）。
4. 慢慢开合上盖，桌面就会跟着折叠成磨砂玻璃。
5. 方向反了点 **「翻转方向」**，幅度不合适点 **「灵敏度 −/＋」**。
6. 不折叠时叠加层自动隐藏，桌面保持原生清晰；合盖才浮出玻璃效果。

> **两种操作方式，任选**：
> - **控制面板按钮**（推荐）：鼠标直接点，随时可用，不依赖控制台。
> - **键盘**：需先点一下**控制台窗口**获得焦点（若你的启动方式没有控制台，就用面板）。
>
> 面板是普通窗口，`Alt+Tab` 能找到它。

### 控制面板按钮

| 按钮 | 作用 | 等价键盘 |
|---|---|---|
| ① 标定基准帧 | 把当前画面设为基准 | `SPACE` |
| 翻转方向 | 合盖方向反了按这个 | `F` |
| 灵敏度 −/＋ | 调整 SCALE | `+` / `-` |
| 切手动 / 切自动 | 跟随角度 ↔ 手动覆盖 | `R` |
| 浓度清零 / 浓度拉满 | 手动快速设置折叠浓度 | `←` / `→` |
| ⚙ 设置… | 打开参数设置窗口（改完即时生效） | — |
| 退出 | 结束程序 | `ESC` |

### 参数设置窗口

点控制面板的 **「⚙ 设置…」** 打开 —— **Windows 11 设置应用（WinUI/Fluent）风格**，
外观与动画逐项对齐 [Class-Widgets](https://github.com/Class-Widgets) 所用的 RinUI 库：

- **自绘标题栏**（48px）：应用图标与标题、最小化/最大化/关闭
- **图标导航栏**：用 Windows 11 官方的 **Fluent System Icons**（随项目打包，5656 个图标）；
  可折叠成 40px 纯图标栏；「关于」固定在底部；选中项左侧有主色指示条（从中心生长）
- **内容区独立图层**：内容区是比导航栏/标题栏**亮一档**的圆角图层（`appLayer`），
  带描边与左上圆角，形成 WinUI 的层次感
- **卡片式设置项**：Fluent SettingCard（内边距 18/16、图标 22px、标题+说明+实时数值）
- **动画**：指示条从中心生长（667ms）、悬停/选中背景色渐变（187ms）、
  页面切换淡入+上滑（187ms/667ms）、导航折叠（250ms），缓动曲线与 RinUI 一致
- **桌面透出**：窗口启用 DWM **Mica** 材质，背景半透明，桌面壁纸的色调会淡淡透出来

| 页面 | 内容 |
|---|---|
| **折叠效果** | 最大转角、眼距、浓度平滑 |
| **模糊质感** | 模糊强度、变暗程度、采样次数 |
| **摄像头** | 摄像头索引、角度灵敏度、反向、最少匹配点、标定说明 |
| **性能显示** | 抓屏频率、显示阈值、性能提示 |
| **关于** | 品牌条（图标 / Windows Duo / 版本号 / 一句话定位）、原理、快速上手、控制面板按钮对照、配置与状态、运行环境与开源致谢 |

「关于」页的版本号、运行环境、配置文件路径都来自 `app_info.py`（不在 QML 里写死），
发版时只改 `APP_VERSION` 一处。

改动**立即生效**，可以边拖边看屏幕效果。「保存为默认」写回 `config.json`；
「恢复默认」回到上次保存的值。摄像头索引改动需重启程序。

### 应用图标

图标只有一份素材（根目录 `icon.png`），三处显示都从它派生：

| 位置 | 怎么来的 |
|---|---|
| 设置窗口标题栏左下角 | QML `icon: App.iconUrl`（读 `assets/icon.png`） |
| 任务栏 | `app_info.apply_app_icon()`：`setWindowIcon` + `SetCurrentProcessExplicitAppUserModelID`（否则任务栏显示的是 python.exe 的图标） |
| EXE 本身 | `build_exe.py --icon assets/icon.ico`（多尺寸 16~256，写进可执行文件资源段） |

`assets/` 下的两份由 `build_exe.py` 从根目录 `icon.png` 自动生成（存在且比原图新就跳过）。
换了图标素材后重跑一次打包即可；`assets/` 是入库的，所以别人 clone 下来也能直接打出带图标的 EXE。


### 主题自动跟随 Windows

设置窗口和控制面板的**明暗模式**和**主色**都自动取自系统：

| 项目 | 来源 |
|---|---|
| 明暗模式 | `HKCU\...\Themes\Personalize\AppsUseLightTheme` |
| 主色 | `HKCU\Software\Microsoft\Windows\DWM\AccentColor`（失败回退 `DwmGetColorizationColor`，再回退默认蓝 `#0078D4`）|

配色用的是 Fluent 的半透明叠加色（如卡片 `rgba(255,255,255,0.0512)`），
这样 Mica 才能透出来。在 Windows 设置里改主题色或切换深/浅色，程序**会自动刷新**
（1.5 秒内），不用重启。

## 打包成 EXE

```bash
python build_exe.py
```

产物就一个文件：

```
dist/WindowsDuo.exe     单文件，双击即可运行（无需装 Python）
```

EXE 的图标与版本信息都会写进可执行文件：资源管理器里能看到 `WindowsDuo` 图标，
右键「属性 → 详细信息」显示产品名、版本号（当前 `0.0.0.1`）、版权——
这些值同样取自 `app_info.py`，与「关于」页显示的是同一份。

首次运行时，程序会在 EXE 旁边自己长出三样东西——都是可删的，删了会自动重建：

| 运行时生成 | 说明 |
|---|---|
| `config.json` | 参数文件。没有就按出厂默认值生成一份，改完即时生效并自动保存 |
| `windows_duo.log` | 运行日志（打包版没有控制台，日志是唯一排查入口） |
| `RinUI/config/rin_ui.json` | RinUI 保存自身主题状态的文件（约 1 KB），属正常现象 |

`--windowed` 打包后没有控制台，所以**键盘快捷键不可用，请用控制面板的按钮**（功能完全等价）。
详细的用法说明就在程序内：面板「设置…」→ 左下角「关于」。

## 配置

[config.json](config.json) 是**唯一参数入口**。推荐用设置窗口改（即时生效），也可以直接编辑文件后重启。

| 键 | 含义 |
|---|---|
| `camera_index` | 摄像头索引 |
| `scale` / `sign` | 物理俯仰角 → 折叠浓度的比例 / 方向 |
| `max_tilt_deg` | 最大玻璃转角。**默认 62°**：角度再大视线大量出界会变成黑幕 |
| `eye_dist_h` | 眼睛到界面平面距离（屏高倍数），影响透视强度 |
| `blur_spread` | 单位间隙 → 模糊半径，越大越糊 |
| `darkening` | 磨砂玻璃吸光，越大越暗 |
| `max_taps` | 单像素最多采样次数，性能/质量权衡 |
| `smoothing` | 折叠浓度平滑系数，越小越顺滑 |
| `refresh_hz` | 叠加层抓屏频率（桌面内容不需要 60Hz 刷新） |
| `show_threshold` | 浓度低于此值隐藏叠加层 |
| `min_matches` | 低于此匹配数认为跟丢（不低于 4，`findHomography` 的硬性要求） |

### 键盘（需先点一下控制台窗口获得焦点）

| 键 | 作用 |
|---|---|
| `SPACE` | 标定基准帧（上盖**完全展开**时按下） |
| `F` | 翻转角度方向（合盖时效果反了按这个） |
| `+` / `-` | 调整灵敏度 SCALE |
| `↑` / `↓`、`W` / `S` | 手动调浓度 ±3% |
| `←` / `A`、`→` / `D` | 浓度清零 / 拉满 |
| `R` | 在「手动覆盖」与「角度自动」之间切换 |
| `ESC` / `Q` | 退出 |

## 已知问题

- 摄像头必须用**上盖自带的那颗**（会随开合转动的），否则识别不到角度。
- 场景需要足够纹理，ORB 才能匹配到足够特征点。
- 本机 Intel 驱动只提供 forward-compatible 上下文，故用 core profile；若你的显卡支持
  compatibility，代码无需改动，仍然可用。
- `.bat` 文件只用 ASCII（cmd 按 GBK 解码中文会乱码并当命令执行）。
